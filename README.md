## “原生 IP”到底怎么判定，IDC 原生和家宽双 ISP 差在哪

原生 IP 的判定标准只有一条：这个 IP 段在 whois 里的注册主体，和机房所在国一致。新加坡原生 IP，就是分到的 IPv4 在 whois 里注册地写的是新加坡，而不是机器摆在新加坡、IP 段却从美国或欧洲广播过来。

广播 IP 的问题出在平台读到的归属地和你以为的不一样：

- **TikTok** 按登录时的 IP 判断账号所在地。广播 IP 常被识别成其他地区，账号定位错乱，推流分配也会异常。
- **Shopee、亚马逊**这类电商风控会查 IP 归属地与店铺注册地是否一致，不一致就进审核队列。
- **Netflix、Disney+、ChatGPT** 按 IP 注册地做地区限制，广播 IP 经常卡在门口，页面能开但内容区不对。

WePC 新加坡页面上的两个说法要分开看。“原生 IDC IPv4”指的是 IP 注册地正确、但 IP 段属于数据中心；“双 ISP 家宽 IP”指的是 IP 段带住宅或家宽属性。两者都是原生 IP，差别在平台风控模型里的权重。多数平台对数据中心段的评分天然低于住宅段，这是买家宽那条多花 8 澳元的理由。

但住宅属性不是免死金牌。IP 纯净度是动态的，同一段地址今天干净，明天可能因为别人的使用行为被标记。这一点对 IDC 原生和家宽原生一样成立。
